# 📊 HR Sales Insights Dashboard

An interactive Business Intelligence dashboard built using **Power BI** to analyze HR sales performance, employee productivity, revenue trends, and business KPIs. This project transforms raw HR sales data into actionable insights that help management make data-driven decisions.

---

## 📌 Project Overview

The HR Sales Insights Dashboard provides a comprehensive view of sales performance from an HR perspective. It enables decision-makers to monitor employee contributions, revenue generation, sales trends, and key business metrics through interactive visualizations.

The dashboard is designed to answer critical business questions such as:

- Which employees generate the highest sales?
- How is revenue performing over time?
- Which departments contribute the most?
- What are the overall sales KPIs?
- Which regions require improvement?
